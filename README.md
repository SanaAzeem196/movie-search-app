# Movie Search App

This project is a small movie discovery app built with React and Vite. It lets users search for movies, browse a grid of results, and view more details about a selected title.

## Features

- Search movies by title
- Display matching movie cards with poster images and basic information
- Open a modal to see additional movie details
- Clean, responsive UI for browsing on desktop and mobile

## Tech Stack

- React
- Vite
- OMDb API for movie data

## How it works

The app sends a search query to the OMDb API and renders the returned movies in a responsive grid. Clicking a movie card opens a modal with more details such as plot, rating, and release year.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal to use the app.
